# Polish terminology glossary

Every Polish string in StockWatch uses the terms below. Terms come from the Polish editions of the
standard references and from Polish market institutions and brokers; where Polish practice keeps the
English name (several indicators, harmonic names), so do we. Where two Polish forms are accepted, the
one used here is chosen for consistency with the rest of the glossary; the alternative is noted.

Conventions:

- Abbreviations stay as they are (RSI, MACD, ATR, VWAP, PRZ, R:R). Where a term is explained, the
  Polish full name follows in parentheses the first time: "RSI (wskaźnik siły względnej)".
- Pattern names are lower case in running text, as in Polish technical literature ("formacja objęcia
  hossy"), and capitalised only at the start of a label or heading.
- Numbers: decimal comma, space as the thousands separator: `1 234,56`; percentages without a space:
  `12,5%`. Ratios keep the decimal comma too: `0,618`, `1,13–1,618`.
- Dates: `8 paź 2026`; months alone in the nominative: `październik 2026`; weeks: `5–9 paź 2026`.
  A period inside a sentence goes in parentheses ("Zanegowano (marzec 2025), ponieważ…"), which reads
  correctly for a day, a week and a month alike.
- Gender-neutral forms: address the user without gendered verbs ("Twój wybór pozostał bez zmian", not
  "zmieniłeś"), and use a colon instead of a number that would need agreement ("Wczytane świece: 12").
- Counts use the four plural forms (`.one/.few/.many/.other`; `other` is for fractions).

## Where the Polish text lives

- Interface text: `messages.properties` / `messages_pl.properties` (`js.*` keys reach the scripts).
- Text that Java code builds (errors, labels, summaries, score evidence, alert emails):
  `i18n/server-messages.txt` and `i18n/server-labels.txt`, keyed by the English text. Services keep
  producing English because their results are cached, stored and shared; pages, JSON responses and
  emails translate it where it is shown, so older stored English text is translated as well.
